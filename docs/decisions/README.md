# Decisions

One file per decision, numbered in the order they are taken (`0001-search-stack.md`, ...), each saying what was decided,
why, and what it costs.

`0001-search-stack.md` is written after the bake-off pilot. A run of the harness drafts it for you as
`results/<run-id>/adr_draft.md`: copy it here, check the numbers against `report.md`, and write down the owner's call on
vendor terms and on Google-derived data, which the harness cannot decide.
